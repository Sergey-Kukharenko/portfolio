# Sergey Kukharenko — Portfolio · Arc.

Личный сайт-портфолио: кейсы, опыт, стек и проекты в одном месте.
**Arc.** — сокращение от Architect: *the art of structure*. В коде тот же знак
становится дженериком `Arc<T>`, где T — то, что строится: код, решения, жизнь.

В продакшене я пишу на Vue / Nuxt, а этот сайт — моя площадка для React:
архитектура, анимации, доступность и производительность на уровне продакшена.

**Live:** https://sergeykukharenko.vercel.app/ · English: https://sergeykukharenko.vercel.app/en/

## Стек

- **React 18** + **TypeScript**
- **Vite** — сборка и dev-сервер, плюс SSR-сборка для пререндера
- **Tailwind CSS** — стили
- **Framer Motion** — вся анимация: layout-переходы, shared layout (`layoutId`),
  spring-физика, scroll-linked эффекты; фичи грузятся лениво через `LazyMotion`
- **prism-react-renderer** — подсветка синтаксиса в разделе «Код»
- **Vercel Web Analytics** — статистика без cookies

## Что внутри

- **Шапка-«остров»** в духе Dynamic Island: прогресс чтения и текущий раздел
  как `Arc<Раздел>`, по клику — меню разделов, короткие уведомления (например,
  «Скопировано»)
- **Hero** — анимированный градиентный фон, строка бренда
  `Arc<Code / Decisions / Life>` с побуквенной сменой слов, счётчики
- **Обо мне** и **Кейсы** — три истории из коммерческой работы: задача,
  решение, результат
- **Опыт** — таймлайн компаний с раскрывающимися карточками и линией
  прогресса; длительность считается из дат, так что не устаревает
- **Навыки** — стек по категориям и интерактивная палитра бренда
- **Код** (только с мышью) — примеры рекурсии на JS / TS / Vue / React / Nuxt /
  Next с подсветкой в цветах бренда
- **Проекты** — React / Next.js вне работы и Vue / Nuxt; фильтр, плавное
  «Показать все / Свернуть», карточки раскрываются в модалку через `layoutId`
- **Контакты** — Telegram, почта, WhatsApp, hh.ru, LinkedIn, GitHub;
  копирование в буфер одним кликом
- **Командная палитра (⌘K)** — поиск по разделам, проектам, опыту и действиям
- **Кастомный курсор** на устройствах с мышью
- Две языковые версии (`/` и `/en/`), каждая пререндерится в статический HTML
  со своими `<title>`, описанием, OG-тегами и hreflang
- Доступность: навигация с клавиатуры, видимый фокус, `prefers-reduced-motion`
- Производительность: ленивые чанки, никаких анимированных `filter: blur()` —
  мягкие свечения нарисованы градиентами, чтобы Safari / iOS держали частоту
  кадров

## Разработка

```bash
npm install
npm run dev       # локальный сервер (Vite)
npm run build     # tsc + клиентская и SSR-сборка + пререндер ru / en
npm run preview   # предпросмотр прод-сборки
```

## Структура

```
src/
  components/
    Island/          — шапка-«остров»: полоса, меню, уведомления
    CommandPalette/  — ⌘K-палитра
    ui/              — мелкие переиспользуемые компоненты
  data/       — контент: опыт, кейсы, проекты, навыки, сниппеты кода, палитра
  i18n/       — словари ru / en и <head> для каждой версии
  lib/        — хуки, пружины, навигация, тема подсветки
  icons.tsx   — inline SVG-иконки
scripts/
  prerender.mjs — запекает HTML для / и /en/ после сборки
```
