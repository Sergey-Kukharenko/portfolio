# Sergey Kukharenko — Portfolio

Личный сайт-портфолио: опыт, стек, pet-проекты и примеры кода в одном месте.
Сделан как практика и демонстрация Framer Motion — почти каждый интерактивный
элемент на сайте что-то анимирует.

**Live:** https://sergeykukharenko.vercel.app/

## Стек

- **React 18** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **Tailwind CSS** — стили
- **Framer Motion** — вся анимация: layout-переходы, scroll-linked эффекты,
  spring-физика, кастомный курсор
- **prism-react-renderer** — подсветка синтаксиса в разделе «Код»

## Что внутри

- **Hero** — анимированный фон, печатающийся подзаголовок ролей, счётчики
- **Обо мне / Опыт** — таймлайн компаний с раскрывающимися карточками и
  scroll-линией прогресса
- **Навыки** — стек по категориям + интерактивная палитра фирменных цветов
  Framer Motion
- **Код** — примеры рекурсии на JS/TS/Vue/React/Nuxt/Next с подсветкой в
  той же цветовой палитре
- **Проекты** — карточки pet-проектов, раскрывающиеся в модалку через
  shared layout transition (`layoutId`), с фильтром по стеку
- **Контакты** — Telegram, почта, WhatsApp, hh.ru, LinkedIn, GitHub
- **Командная палитра (⌘K)** — быстрый переход по разделам, проектам и
  действиям с fuzzy-поиском
- **Кастомный курсор** — увеличивается на интерактивных элементах, точечная
  цветовая инверсия над заголовком Hero
- Поддержка `prefers-reduced-motion`, OG/Twitter-теги для превью в соцсетях

## Разработка

```bash
npm install
npm run dev       # локальный сервер (Vite)
npm run build     # прод-сборка (tsc + vite build)
npm run preview   # предпросмотр прод-сборки
```

## Структура

```
src/
  components/   — секции и переиспользуемые UI-компоненты
  data/         — контент (опыт, проекты, навыки, сниппеты кода, палитра)
  icons.tsx     — inline SVG-иконки
  lib/          — тема подсветки синтаксиса
```
